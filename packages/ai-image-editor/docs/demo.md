# Live demo

Try the editor below. Type a prompt (or pick a preset chip) and hit generate,
and the result materialises out of the shimmer. Use the **controls** to
reconfigure its layout and behaviour live.

<AiImageEditorDemo />

::: tip Generate, then edit
After the first result the editor flips to **edit** mode. Generate again to
chain edits, pick a different aspect ratio, or scrub the prompt history strip.
:::
